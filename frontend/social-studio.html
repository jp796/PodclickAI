Setup Instructions

Required Environment Variables

Add these to your .env file, then restart the server.

META_APP_ID — Facebook App ID (from developers.facebook.com)
META_APP_SECRET — Facebook App Secret
LINKEDIN_CLIENT_ID — LinkedIn OAuth Client ID (from linkedin.com/developers/apps)
LINKEDIN_CLIENT_SECRET — LinkedIn OAuth Client Secret
Redirect URIs to register:
Facebook App → Valid OAuth Redirect URIs: http://localhost:8765/api/social/meta/callback
LinkedIn App → Authorized Redirect URLs: http://localhost:8765/api/social/linkedin/callback
