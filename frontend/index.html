📁 Google Drive Integration
Checking…
Auto-creates episode asset folders in Google Drive and uploads your MP3 + transcript. Guests get a shareable link.
Setup (one-time)
  1. Go to Google Cloud Console → Create a Service Account
  2. Enable the Google Drive API for your project
  3. Download the JSON key file for the service account
  4. Add to your .env file:
GOOGLE_SERVICE_ACCOUNT_JSON=/path/to/service_account.json
GOOGLE_DRIVE_PARENT_ID=your_drive_folder_id  # optional
5. Share your Google Drive folder with the service account email (give Editor access). Then restart the server.
▶️ YouTube Integration
Checking…
subscribers · videos
View channel ↗
Upload podcast episodes directly to YouTube. Supports full episodes and vertical Shorts. Videos default to Private until you're ready to publish.
Setup (one-time)
  1. Go to Google Cloud Console → Credentials
  2. Create an OAuth 2.0 Client ID (Web Application type)
  3. Add http://localhost:8765/api/youtube/callback as a redirect URI
  4. Download JSON → rename to youtube_client_secrets.json → place in the data/ folder
  5. Click Connect YouTube above and authorize your channel
💡 Enable the YouTube Data API v3 in your Google Cloud project before connecting.
