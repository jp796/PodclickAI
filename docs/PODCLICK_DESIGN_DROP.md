## THE PRODUCT IN ONE SENTENCE

PodClick is a content operations system for personal-brand-driven real estate agents, built around an AI operator named **Brick** who runs the user's content site like a general contractor.

---

## THE BRAND DNA

The metaphor is **construction**. Every screen should feel like a job trailer that got a serious design upgrade — functional, direct, no fluff. Think: worn blueprint drawings, stenciled type, industrial gauges, site reports. Not Silicon Valley. Not a YouTube creator dashboard. A working professional's operations center.

The product has three sacred elements:
- **Brick** — the AI general contractor. He's a character, not a chatbot.
- **The Foundation** — the user's voice fingerprint. The moat.
- **The Blueprint** — the user's brand profile. The source of truth.

## TYPOGRAPHY SYSTEM

This is the most important section. The font stack is what makes PodClick feel different from every other AI tool.

```css
/* Google Fonts import */
@import url('https://fonts.googleapis.com/css2?family=Big+Shoulders+Display:wght@400;600;700;900&family=Azeret+Mono:wght@300;400;500;600&family=Barlow:wght@300;400;500;600&family=Barlow+Condensed:wght@400;500;600;700&display=swap');

--font-display: 'Big Shoulders Display', sans-serif;
--font-mono:    'Azeret Mono', monospace;
--font-body:    'Barlow', sans-serif;
--font-cond:    'Barlow Condensed', sans-serif;
```

### When to use each font

| Font | Use for | Example sizes |
|---|---|---|
| **Big Shoulders Display** | Page titles, large stats, section headers, day numbers in calendar, tier names | 24px–90px, weight 700–900 |
| **Azeret Mono** | All metadata labels, timestamps, section eyebrows, data readouts, percentage values | 8px–12px, weight 400–500 |
| **Barlow Condensed** | Navigation items, tags, secondary buttons, crew names, status text | 11px–16px, weight 500–600 |
| **Barlow** | Body copy, descriptions, Brick's speech, longer text | 12px–14px, weight 300–400 |

### Typography patterns

**Page title:** Big Shoulders Display, 700, 26px, letter-spacing 0.06em
**Stat number (big):** Big Shoulders Display, 900, 44–72px, letter-spacing 0.02em
**Section eyebrow:** Azeret Mono, 400, 9px, uppercase, letter-spacing 0.16em, color --text-dim
**Nav item:** Barlow Condensed, 500, 13px, letter-spacing 0.02em
**Card label:** Azeret Mono, 400, 9px, uppercase, letter-spacing 0.12em, color --text-dim
**Body / descriptions:** Barlow, 300–400, 13px, line-height 1.55
**Button text:** Big Shoulders Display, 700, 14–16px, letter-spacing 0.08em (primary buttons only)
**Tag / pill text:** Azeret Mono, 400, 8–9px, uppercase, letter-spacing 0.10em

### NEVER use
- Inter, Roboto, Space Grotesk, SF Pro, or any system font
- Font-weight 400 for headlines
- More than 4 font families

## VOCABULARY — NEVER BREAK THESE

Every user-facing string must use these terms. This is non-negotiable.

| Don't write | Write instead |
|---|---|
| Dashboard | Walk-through (daily report) or Job Site (project view) |
| Settings | Permit (for Brick's autonomy) or the specific page name |
| AI agent / bot / assistant | Brick |
| Brand profile | Blueprint |
| Voice training / AI corpus | Foundation |
| Voice match score | Foundation match |
| Publish / go live | Close / Closing |
| Approval queue | Punch List |
| Autonomy level | Brick's Permit |
| Campaign / project | Project |
| Competitor analysis | Comps |
| Approve | Sign off |
| Reject | Send back |
| Delete a project | Tear it down |
| Schedule | Line it up |
| Published | Live / Closed clean |

### Banned words — zero tolerance
leverage · synergy · unlock · empower · cutting-edge · game-changer
seamless · frictionless · AI-powered · robust · holistic · workflow
supercharge · effortless · revolutionize · "at your fingertips"

### Brick's voice rules (when generating his dialogue)
- Lead with the action: "Laid 6 posts." NOT "I'm happy to share..."
- Use real data: numbers, dates, percentages
- Have opinions: "I'd shift that clip to Tuesday."
- Stay short: 1–3 sentences max
- Never say "as an AI" or "I'm a language model"
- Never use: "Great question!", "Absolutely!", "I hope this helps!"
- Construction-flavored: "solid build", "closed clean", "punch out the list", "we solid?"

## MOTION & INTERACTION NOTES

- Hover transitions: 0.12s ease
- Panel slides: 0.25s ease (Brick chat)
- No bouncy animations — this is a job site, not a toy
- Loading states: pulse animation on --border-lit, no spinning wheels
- Status dots: box-shadow glow on --green for live/active states
- Brick's avatar: subtle orange box-shadow glow at all times

---

## WHAT NOT TO BUILD

- No purple gradients anywhere
- No glassmorphism / frosted glass effects
- No rounded corners >8px on cards (keep it angular, workmanlike)
- No floating action buttons
- No onboarding modals that pop up over the whole screen
- No skeleton loaders with blue shimmer
- No emoji in operational UI (🔨 is acceptable in Brick's casual chat only)
- No "AI-powered" badges or marketing language inside the app
- No generic SaaS nav patterns (no mega-menus, no hamburger menus on desktop)
